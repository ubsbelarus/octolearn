Геймифицированная платформа OctoLearn предназначена для изучения и повторения языков как самостоятельно, так и с преподавателями. Приложение работает полностью в офлайн‑режиме после загрузки материалов, не требует сервера и сохраняет все данные локально. Ученикам доступно 16 типов интерактивных заданий: карточки, перевод, аудирование, диктант, тренировка тонов, рисование иероглифов и другие. Система геймификации включает начисление опыта (XP), серии (streak) и звёзды за успешное прохождение уроков. Встроенный словарь поддерживает поиск, фильтрацию и озвучивание слов. Интерфейс адаптирован под тёмную тему и режим для дальтоников. Для учителей создан визуальный редактор с drag‑and‑drop, позволяющий структурировать курсы по главам, создавать и редактировать задания, а также импортировать и экспортировать содержимое в формате JSON. Проверка результатов учеников осуществляется с использованием цифровой подписи, что гарантирует достоверность данных. EN:

The gamified platform OctoLearn is designed for learning and reviewing languages either independently or with teachers. The application works fully offline after loading materials, requires no server, and stores all data locally. Students have access to 16 interactive exercise types: flashcards, translation, listening comprehension, dictation, tone training, handwriting characters, and more. The gamification system includes experience points (XP), streaks, and stars for successful lesson completion. The built‑in dictionary supports search, filters, and text‑to‑speech. The interface includes dark mode and a color‑blind friendly theme. Teachers are provided with a visual drag‑and‑drop editor to structure courses into chapters, create and modify exercises, and import/export content in JSON format. Student results are verified using digital signatures to ensure data authenticity. The platform is under active development: upcoming features include course hosting services, video calls with shared whiteboard and presentations, a mini‑game editor, speech practice with recognition, ready‑made courses for self‑study and tutor‑led sessions, support for any language, and a cloud database for teachers to share lessons.
